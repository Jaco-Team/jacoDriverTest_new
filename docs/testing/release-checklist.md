# Release checklist

## Цель документа

Этот чеклист нужен для повторяемой проверки перед релизом `jacoDriverTest`.

Автоматический baseline уже добавлен. Чеклист разделен на:

- локальную проверку;
- GitHub-проверку;
- ручные сценарии.

## Локальный automatic baseline

Перед релизом должны проходить:

```bash
npm run lint
npm run typecheck
npm run test:unit
```

Подробности:

- [docs/quality-baseline.md](../quality-baseline.md)

## GitHub baseline перед merge

После внедрения GitHub Actions перед merge также должен быть зеленым check:

- `CI Baseline / lint-typecheck-unit`

Он должен запускать:

- `npm run lint`;
- `npm run typecheck`;
- `npm run test:unit -- --ci`.

Подробности:

- [docs/testing/git-checks.md](./git-checks.md)

## Ручные сценарии перед релизом

### Запуск приложения

Проверить:

- приложение стартует;
- экран приветствия/авторизации открывается корректно;
- Sentry/AppMetrica/YaMap initialization не ломает запуск;
- нет crash на холодном старте.

### Авторизация

Проверить:

- вход;
- обработку ошибки входа;
- правильный вход без CAPTCHA, если сервер её не потребовал;
- появление SmartCaptcha только после `captcha_required` при входе;
- обязательную SmartCaptcha перед отправкой кода восстановления;
- SSO: системное окно, web-вход, возврат по deep link и обмен кода на токен;
- восстановление пароля с шестизначным SMS-кодом;
- сохранение/чтение Bearer-токена в Keychain/Keystore.

### Заказы

Проверить:

- список заказов открывается;
- обновление списка работает;
- карточка заказа отображает ключевые поля;
- действия доступны только в ожидаемых состояниях;
- модалка подтверждения открывается и закрывается корректно.

### Карта заказов

Проверить:

- карта открывается;
- маркеры отображаются;
- группировка заказов не ломает список;
- открытие заказа с карты работает;
- состояние пустого списка не ломает экран.

### Геолокация

Проверить:

- permissions не ломают запуск;
- позиция курьера обновляется;
- повторное нажатие определения позиции снова показывает/обновляет маркер без
  необходимости уходить с карты;
- GPS-зависимые действия ведут себя ожидаемо.

### Настройки

Проверить:

- изменение размера шрифта;
- изменение темы/масштаба карты, если зона затрагивалась;
- выбор кафе показывает реальные точки в формате «город, точка», сохраняет выбор,
  выделяет текущую точку и прокручивается при длинном списке;
- сохранение настроек.

Для demo-аккаунта дополнительно проверить фейковое удаление и повторный вход; для
обычного аккаунта кнопки удаления быть не должно.

### Статистика и расчет

Проверить:

- выбор дат;
- нормализацию диапазона;
- обновление данных;
- состояние ошибки API.

### Обратная связь

Проверить:

- список обращений;
- создание обращения;
- выбор изображения/камеры, если зона затрагивалась.

## Что нельзя делать перед релизом без уверенности

Нельзя:

- выполнять опасные реальные действия с заказами только ради проверки;
- оставлять включенный fake/dev режим;
- выпускать релиз с неизвестным красным baseline;
- менять startup или store без повторной проверки основных сценариев.
