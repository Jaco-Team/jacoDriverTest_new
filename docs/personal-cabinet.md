# Личный кабинет курьера в приложении

## Этап от 25.11.2026

Рабочая ветка приложения — `main`. Эталон — согласованный ЛК сайта
в `jaco_driver_site` на ветке `api-laravel`.
Пункт «Личный кабинет» идёт после «Карты заказов» в боковом меню после
входа с обычным или локальным Laravel API. Android и iOS используют один экран.

- Подключён `GET /api/v1/cabinet` с Bearer-токеном действующей сессии.
  ФИО берётся из сессии. Профиль показывает фото, должность, закреплённое
  кафе, дату регистрации и стаж. Для отсутствующего фото или ошибки
  загрузки используется круглая иконка человека.
- График, расчёт и статистика открывают существующие разделы. Статистика
  видна по тому же флагу рабочего кафе, что и пункт бокового меню.
- Общий срок медкнижки показан в заголовке. После раскрытия видны осмотры
  и анализы по срокам, ближайшие даты выделены жирным. Материалы —
  «Инструкция курьера» и «Общие правила», ссылки открываются в браузере.
  Выданная форма отображается при наличии данных.
- Промокоды берутся из ответа API. Код копируется в системный буфер,
  после копирования видна галочка. Блок отображается при наличии кодов.
  В конце расположен образец метки с действующими настройками оформления,
  цвета и формата времени. Ссылка «Настройки» открывает общий экран настроек.
- При загрузке видна шапка под полупрозрачным затемнением. Карточки
  появляются вместе, после данных, настроек и фото. При ошибке фото или
  ожидании дольше восьми секунд показывается иконка.
- Ответ ЛК хранится в памяти только пока экран открыт при наличии сети.
  Офлайн доступны имя из сессии, переходы, метка из настроек и заголовки
  раскрытых разделов «Профиль» и «Документы и допуски». Под шапкой появляется
  общая плашка «Нет подключения к интернету». После возврата сети данные
  загружаются заново и появляются в раскрытых разделах. Запрос отменяется
  при уходе с экрана и при потере связи.

## Проверка в Android и iPhone

Используйте запущенный локальный Laravel с тестовой БД и аккаунт №2563.
Проверка обоих подключений, запуск API и варианты сборки описаны в
[инструкции по тестовой БД](./testing/test-database.md#4-подключить-android-и-iphone).
Реквизиты №2563 лежат в приватном файле с тестовым аккаунтом.

Для Debug запустите Metro в отдельном терминале:

```bash
cd /Users/denis/Public/work/jacoDriverTest_new
npm run start:local-api
```

Для подключённого Android-эмулятора в другом терминале:

```bash
cd /Users/denis/Public/work/jacoDriverTest_new
adb -s emulator-5554 reverse tcp:8080 tcp:8080
npm run android -- --device emulator-5554 --no-packager
```

Для установленного iPhone 17 с iOS 26.2:

```bash
cd /Users/denis/Public/work/jacoDriverTest_new
npm run ios:pods -- --deployment --no-repo-update &&
npm run ios -- --simulator "iPhone 17" --no-packager
```

Если имена устройств отличаются, возьмите их из `adb devices` и
`xcrun simctl list devices booted`. Для физического iPhone используйте
доступный с устройства локальный API по инструкции тестовой среды.

В обоих клиентах:

1. Войти как №2563 и открыть ЛК из бокового меню. Сверить с сайтом ФИО,
   фото, закреплённое кафе «Тольятти, Ленинградская 47», дату регистрации
   20.02.2018 и стаж. Проверить шапку при загрузке и иконку при ошибке фото.
2. Раскрыть «Документы и допуски». Общий срок до 22.09.2027,
   «Санитарный минимум» первым с жирной датой. Восемь остальных сроков
   до 05.09.2028. Открыть обе ссылки на материалы.
3. Если тестовый код истёк, выполнить команду ниже и открыть ЛК заново.
   Проверить карточку «Действует сегодня», часы 11:00–19:00 и копирование.
4. Проверить переходы, возврат в ЛК и смену рабочего кафе при наличии
   нескольких доступных точек. Закреплённое кафе в профиле остаётся по БД,
   кнопка «Статистика» следует флагу выбранной рабочей точки. Для №2563
   добавьте тестовый доступ к Матросова 32 командой ниже. Перезапустите
   приложение, выберите Матросова 32 в настройках и откройте ЛК. В профиле
   ожидается Ленинградская 47. Повторите на сайте и обеих платформах.
5. Проверить светлую и тёмную темы, шрифт 26 и прокрутку. В образце метки
   между значком и подписью должен быть видимый отступ.
   Разделители между полями профиля и осмотрами должны быть видны.
   У рабочих ссылок, материалов и настроек карты стрелка справа,
   у кнопки копирования промокода видна рамка.
6. Раскрыть «Профиль» и «Документы и допуски», затем отключить сеть.
   Остаются ФИО, рабочие переходы, метка и заголовки раскрытых разделов.
   Фото заменяется иконкой, подробности и промокоды скрываются. Под шапкой
   видна общая плашка. Включить сеть и дождаться данных в раскрытых
   разделах. Отдельно проверить отсутствие старых данных ЛК при входе
   в другой аккаунт.
