# Офлайн-карты приложения

В настройках добавлен раздел «Офлайн-карты» по текущему `jaco_driver_site`,
ветка `api-laravel`, коммит `0095596` (локальное дерево без изменений).
Эталон: `features/offline-map/ui/OfflineCityMapsSettings.tsx`,
`entities/offline-map/model/offlineMap.store.ts` и `docs/maps.md` сайта.

## Пользовательский сценарий

- Города: Самара и Тольятти. Выбор хранится только на устройстве, не меняет кафе,
  аккаунт или фильтр заказов и не требует сохранения общих настроек.
- По умолчанию выбирается город текущего кафе по названию или координатам.
- Перед скачиванием показывается размер пакета из каталога MapKit.
- Порядок блока одинаков с сайтом: город, размер, статус или прогресс, кнопки.
- Действия: «Скачать», «Пауза», «Продолжить», «Обновить», «Удалить».
  Удаление подтверждается в нижней шторке с единым текстом и кнопками «Нет» и
  «Удалить». На сайте дополнительно возможна кнопка «Докачать» для старого
  неполного пакета тайлов; MapKit такого состояния не использует.
- Показываются прогресс, готовность, дата сохранения и ошибки загрузки.
  Ошибка оформляется одинаково с сайтом: отдельная плашка со значком, мягким
  красным фоном и тематическими цветами в светлом и тёмном режиме.
  Частичная загрузка не помечается «Доступна офлайн».
- Скачать можно один город за раз при активной авторизованной сессии и наличии
  интернета. Переход между экранами не останавливает загрузку.
- Потеря сети или уход приложения в фон ставят загрузку на паузу с возможностью
  автоматического продолжения при возвращении в активное приложение с сетью.
  Ручная пауза требует «Продолжить». Выход из аккаунта отключает автопродолжение.
- Незавершённые задания восстанавливаются после перезапуска. Статус сверяется
  с нативным SDK; очищенная карта не остаётся помеченной как готовая.
- Обновление заказов и вход в настройки не начинают скачивание автоматически:
  новый пакет запускается только кнопкой «Скачать», а остановленный — кнопкой
  «Продолжить».
- Если текущий город не скачан, приложение не показывает случайные тайлы из
  временного кэша MapKit как готовую офлайн-карту. Вместо карты отображаются
  та же подсказка и список сохранённых заказов, что и на сайте; карточка заказа
  открывается прямо из списка.

Состояния скачивания, удаления и отсутствующей карты вручную проверены 7 октября
2026 года на Android и iOS и сопоставлены с мобильным сайтом.

Автоматический прогон 7 октября: `lint`, `typecheck`, 111 наборов / 525
Jest-тестов и три нативные регрессии маркеров прошли; Android Debug и iOS Debug
для Simulator успешно собраны без запуска эмуляторов. Тесты отдельно фиксируют
единый текст удаления, пустое состояние без сохранённых заказов и запрет
одновременного скачивания двух городов.

## Отличия от сайта

Приложение сохраняет нативные городские пакеты Yandex MapKit. Сайт сохраняет
растровые тайлы Tiles API в Cache Storage с прямоугольниками и уровнями 10–14.
Границы, детализация и размер пакетов отличаются. В приложение не переносится
браузерный рендерер, серверный Tiles API или его ключ.

Готовность и необходимость обновления определяет MapKit (`completed`, `outdated`,
`need_update`), вместо браузерного срока хранения 29 дней. Нативный SDK проверяет
доступное место перед скачиванием. Скачивание допускается по мобильной сети.
Непрерывная загрузка в фоне не обещается.

Данные карт хранятся в SDK, метаданные и выбранный город — в AsyncStorage
`jaco_mapkit_city_downloads_v1`. Карты общие для устройства; пользовательский
кеш заказов и токен остаются отдельными и очищаются при выходе из аккаунта.
Офлайн-карта не предоставляет новые заказы и не разрешает менять их статусы.

MapKit может показывать ранее закэшированные просмотренные участки, но приложение
не загружает городской пакет автоматически. Наличие подложки на текущем экране не
означает, что весь город доступен без сети; полную готовность проверяем в разделе
«Офлайн-карты».

Debug-сборка для физического iPhone содержит встроенный JS-пакет: при доступном
Metro используются его обновления, без Metro React Native выбирает встроенный
пакет. После изменений JavaScript для офлайн-запуска нужно пересобрать и
установить приложение. Debug-симулятор по умолчанию использует только Metro.
Отладку в авиарежиме подключаем по USB: отключение Wi-Fi прерывает беспроводное
соединение с Xcode. Для релиза отдельно проверяем Release-сборку.

## Проверка на iPhone

Чтобы безопасно показать состояние ошибки в Debug на Android и iPhone, запустите
Metro с принудительным предпросмотром и обновите JavaScript приложения:

```bash
JACO_OFFLINE_MAP_ERROR_PREVIEW=1 JACO_LARAVEL_API=local npm start -- --reset-cache
```

Откройте «Настройки → Офлайн-карты». Выбранный город покажет «Загрузка
прервана», прогресс, тестовую ошибку и действия «Продолжить»/«Удалить».
Нативная пересборка не требуется. Флаг действует только в Debug и не меняет
сохранённую карту; для возврата к обычному состоянию перезапустите Metro без
`JACO_OFFLINE_MAP_ERROR_PREVIEW`.

1. Открыть настройки; проверить размер и готовность ранее скачанной карты.
2. Скачать другой город, поставить на паузу, перейти на другой экран и обратно.
   Загрузка не должна продолжиться без нажатия «Продолжить».
3. Продолжить, отключить сеть, затем включить: загрузка должна возобновиться.
4. Закрыть приложение во время загрузки и открыть снова с сетью: прогресс
   восстанавливается из SDK, завершённая карта показывает «Доступна офлайн».
5. Полностью закрыть приложение, включить авиарежим и открыть карту:
   сохранённые заказы и подложка текущего скачанного города должны отображаться.
6. Удалить пакет с подтверждением. Другой город должен остаться сохранённым;
   обновление заказов не должно скачать удалённый пакет заново.
7. Проверить светлую/тёмную тему, крупный шрифт, малую ширину и нижний Safe Area.

Источник нативного контракта:
[Yandex MapKit: офлайн-карты](https://yandex.ru/maps-api/docs/mapkit/ios/generated/tutorials/map_offline.html).

### Дополнительная проверка плашки и меток

- На карте плашка «Нет подключения к интернету» отображается поверх подложки,
  не увеличивает заголовок и не сдвигает область MapKit при смене сети. Она не
  перехватывает касания; кнопка поворота расположена ниже измеренной плашки.
  Область карты занимает доступное место, без фиксированных размеров окна.
  Компонентные тесты проверяют повторные смены сети без перемонтирования карты;
  точное совпадение нативных касаний проверяется на физическом устройстве.
- После установки этого исправления пользователь проверил карту в авиарежиме
  на iPhone 16 Pro и подтвердил: карточки открываются при касании прямо по тексту
  меток, смещать палец ниже подписи больше не требуется. Подписанная iOS Debug-
  сборка, `lint`, `typecheck`, 109 наборов / 486 тестов — успешно.

- Исправлена Babel-конфигурация: внутренние компоненты React Native используют
  React JSX, компоненты приложения сохраняют NativeWind. На iPhone 16 Pro / iOS
  27.0.1 предупреждение LogBox теперь показывает фон и текст вместо пустой белой
  плашки. Предупреждения debug-сборки не подавляются.
- На этом же iPhone по USB в авиарежиме, без Wi-Fi и сотовой связи, проверены
  отображение карты, открытие меню и карточки сохранённого заказа по метке.
  Пользователь повторил быстрые нажатия/закрытия: метки и карточки работают,
  вылет не повторился. В журнале устройства нет crash report приложения;
  точную причину прежнего вылета установить не удалось.
- Подписанная iOS Debug-сборка, `lint`, `typecheck`, 108 наборов / 466 тестов —
  успешно. Тест шторки проверяет 100 офлайн-циклов с повторными нажатиями,
  группой заказов одного адреса, отсутствием API-вызовов и запоздалыми callbacks.
  Нативный MapKit в этом тесте заменён mock-компонентом.
- В `ios/.xcode.env` убрано отключение упаковки JS для физических устройств.
  Финальная Debug-сборка содержит `main.jsbundle`; после установки по USB и
  полного перезапуска в авиарежиме приложение загрузилось без Metro и
  восстановило список сохранённых заказов. Release-сборка отдельно не проверялась.
